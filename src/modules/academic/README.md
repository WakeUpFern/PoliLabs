# Academic

Academic I implementa prácticas, sesiones y participantes previstos mediante dominio puro, AcademicService, persistencia transaccional y flujo web del laboratorio.

Ver [alcance, reglas, seguridad y validación](../../../docs/architecture/academic.md) y [ADR 0011 (Propuesta)](../../../docs/decisions/0011-academic-sessions.md). No equivale a asistencia ni uso efectivo. Grupos/periodos, Usage, incidencias y vínculo con reservaciones se implementarán en incrementos posteriores.
